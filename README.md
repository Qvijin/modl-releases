Это зеркало списка версий движка Modl: два статических файла на канал (`v1/manifest/stable.json` и `v1/manifest/beta.json`) и подписи к ним, которые читают сайты.
Файлы пишет команда `pnpm release:announce` движка и подписывает их ключом выпуска; страница отдаётся через GitHub Pages.
Руками здесь ничего не правится: сайт отвергает список с испорченной подписью, а следующее объявление остановится на посторонних правках.
